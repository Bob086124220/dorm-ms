About the Project

为高校公寓日常
管理场景设计

本项目为《企业级开发应用》课程设计落地项目，以高校学生公寓日常管理场景为业务载体。系统采用 MVC 三层架构，SSM 技术栈，WAR 包部署，面向系统管理员、宿管、学生三种角色提供差异化界面与权限控制。两周开发周期，3 人协作，Git 分支管理，全链路文档交付。

01

解决传统纸质管理的低效与混乱

传统公寓管理依赖纸质登记和人工传递信息，数据分散、查询困难、审批流程漫长。系统将入住、调宿、报修、晚归、访客全部流程线上化，实现数据集中管理与实时查询。

02

Spring MVC + MyBatis + MySQL

后端采用 SSM 框架，前端 Bootstrap 5 + jQuery + JSP，MVC 三层分层，WAR 包部署至 Tomcat 9。

Spring MVC 5.3MyBatis 3.5MySQL 8.0Bootstrap 5jQuery 3.6Tomcat 9
03

企业级开发标准与文档体系

统一返回格式、全局异常处理、AOP 操作日志、声明式事务、枚举替代魔法值、SQL 预编译防注入。需求 → 架构 → 接口 → 业务逻辑 → 测试验收全链路文档。

控制层Spring MVC：路由、校验、封装
业务层Service：逻辑、事务、状态流转

三层职责严格隔离 · Controller 不写业务 · DAO 不拼 SQL · 横切与业务解耦
