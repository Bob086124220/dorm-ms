# 高校公寓管理系统 — 前端页面风格约束 v2

> 文档版本：v2.1 | 最后更新：2026-07-03
> 适用范围：所有前端页面（JSP + Bootstrap 5.3.3 + jQuery 3.6.0 + FontAwesome 6.5.1）
> 前置依赖：无
> v2 变更摘要：新增 SVG 纸张纹理叠加、页面 eyebrow 组件、骨架屏加载态、空状态双模式、卡片装饰增强、动画时长 transition/@keyframes 区分、4 条新增禁忌、3 条新增 P0 验收项、prefers-reduced-motion 降级
> v2.1 变更摘要（阶段 H）：动画系统重构 — 四核心 @keyframes（fadeUp/fadeIn/slideRight/headerReveal）、`cubic-bezier(0.22, 1, 0.36, 1)` 替代 `ease` 作为 @keyframes 曲线、完整入场编排时间线（1.5s 全序列）、侧栏菜单交错入场、CSS animation 替代 jQuery animate、count-up 升级为 ease-out-cubic + IntersectionObserver、prefers-reduced-motion 全局降级

## 一、设计哲学

本系统采用**杂志风亮色主题**。核心原则：大量留白、克制的强调色、衬线标题与无衬线正文的字体对比、等宽字体承载数据与标签、半调网点底纹增加纸张质感、SVG 分形噪点叠加纸张粗糙纹理。视觉目标为"有呼吸感的校园生活杂志"，而非"装饰性仪表盘"。

## 二、基础设计令牌（Design Tokens）

### 2.1 色彩系统

所有颜色必须使用 `rgb(x, x, x)` 或 `rgba(x, x, x, x)` 格式，禁止使用 hex（`#xxx`）或关键字（`red`、`blue`）。

| 令牌名 | 用途 | 色值 | CSS 变量 |
|:---|:---|:---|:---|
| `--bg` | 页面底层背景（半调网点底色） | `rgb(250, 249, 245)` | `--bg` |
| `--surface` | 卡片、面板、弹窗等浮层背景 | `rgba(255, 255, 255, 0.92)` | `--surface` |
| `--fg` | 主文字、标题 | `rgb(45, 36, 28)` | `--fg` |
| `--muted` | 次级文字、标签、眉标 | `rgb(122, 112, 103)` | `--muted` |
| `--border` | 边框、分割线 | `rgb(235, 230, 223)` | `--border` |
| `--accent` | 主强调色（锗红） | `rgb(196, 69, 58)` | `--accent` |
| `--accent-2` | 辅助强调色（暖橙） | `rgb(212, 132, 90)` | `--accent-2` |
| `--hover-bg` | 行/项 hover 底色 | `rgb(245, 244, 237)` | `--hover-bg` |
| `--stripe` | 表格奇数行条纹色 | `rgba(0, 0, 0, 0.025)` | `--stripe` |
| `--col-line` | 表格列间竖线色 | `rgb(240, 238, 230)` | `--col-line` |
| `--surface-opaque` | 弹窗专用完全不透明白 | `rgb(255, 255, 255)` | `--surface-opaque` |
| `--status-ok` | 成功/处理中状态色 | `rgb(46, 125, 111)` | `--status-ok` |
| `--timeout-bg` | 超时行背景色 | `rgb(255, 243, 205)` | `--timeout-bg` |
| `--accent-soft` | accent 的 10% 透明度版本 | `color-mix(in oklch, var(--accent) 10%, transparent)` | `--accent-soft` |
| `--accent-2-soft` | accent-2 的 12% 透明度版本 | `color-mix(in oklch, var(--accent-2) 12%, transparent)` | `--accent-2-soft` |
| `--fg-soft` | fg 的 6% 透明度版本 | `color-mix(in oklch, var(--fg) 6%, transparent)` | `--fg-soft` |

**v2 新增 token：**

| 令牌名 | 用途 | 值 | CSS 变量 |
|:---|:---|:---|:---|
| `--sidebar-bg` | 侧栏背景（与内容区微差） | `color-mix(in oklch, var(--surface) 88%, var(--bg))` | `--sidebar-bg` |
| `--skeleton-base` | 骨架屏基础色 | `var(--border)` | `--skeleton-base` |
| `--skeleton-shine` | 骨架屏高光色 | `var(--hover-bg)` | `--skeleton-shine` |

**色彩使用规则：**
- 每个屏幕最多使用 2 处 accent 色（如眉标 + 主按钮、侧栏激活态 + 标题强调）
- 不得出现紫色/紫色渐变背景
- 不得出现暖米色/奶油色/桃色/粉色/橙棕色整页背景渐变
- 半调网点底色固定为 `rgb(250, 249, 245)`，其上的网点色固定为 `rgb(237, 234, 229)`

### 2.2 字体系统

| 用途 | 字体族 | 字号 | 字重 | 行高 | 字间距 |
|:---|:---|:---|:---|:---|:---|

| `--gap-sm` | `10px` | 小间距（表格行内 padding、按钮内 gap） |
| `--gap-md` | `16px` | 中间距（卡片内间距、表格单元格 padding） |
| `--gap-lg` | `24px` | 大间距（区块间、侧栏 padding） |
| `--gap-xl` | `40px` | 超大间距（页面级 section 间距） |

**间距规则：**
- 页面顶部到第一个内容块：`48px`（v2 从 40px 加大，制造杂志开篇留白）
- section 与 section 之间：`40px`
- 卡片内部 padding：`24px`
- 表格单元格 padding：`12px 16px`
- 按钮内 padding：`9px 18px`（常规）、`5px 12px`（小号）
- 侧栏分组标题上方间距：`24px`（v2 从 10px 加大，制造目录分区感）

### 2.4 圆角

| 令牌名 | 值 | 用途 |
|:---|:---|:---|
| `--radius` | `8px` | 按钮、输入框、下拉框、小型面板 |
| `--radius-lg` | `12px` | 卡片、数据面板、弹窗、大面板 |

**圆角规则：**
- 所有可交互元素必须有圆角，不得出现直角按钮或直角输入框
- 圆角值只能使用 `8px` 或 `12px` 两个枚举值，禁止出现 `4px`、`6px`、`16px`、`20px` 等中间值
- pill/badge 使用 `999px`（完全圆形端点）

## 三、半调网点底纹 + SVG 纸张纹理

### 3.1 半调网点实现

```css
body {
  background:
    radial-gradient(circle, rgb(237, 234, 229) 0.8px, transparent 0.8px),
    rgb(250, 249, 245);
  background-size: 16px 16px;
}
```

### 3.2 半调网点参数规范

| 参数 | 值 | 说明 |
|:---|:---|:---|
| 网点形状 | 圆形（`circle`） | 不得使用椭圆或方形 |
| 网点半径 | `0.8px` | 直径 1.6px，肉眼可见但不抢视觉 |
| 网点颜色 | `rgb(237, 234, 229)` | 比底色深约 5%，不可过深 |
| 网点间距 | `16px` | 网格密度固定，不可调整 |
| 底色 | `rgb(250, 249, 245)` | 与 `--bg` 一致 |

### 3.3 SVG 纸张纹理叠加（v2 新增）

在半调网点之上叠加 SVG `feTurbulence` 分形噪点，模拟纸张粗糙质感。

**使用方案Y**

**方案 X：**

1. 在 `header.jsp`（所有内容页）和 `login.jsp`（登录页）的 `<body>` 标签后插入隐藏 SVG 滤镜定义：

```html
<svg style="position:absolute;width:0;height:0;overflow:hidden" aria-hidden="true">
  <filter id="paper-grain">
    <feTurbulence type="fractalNoise"
      baseFrequency="0.65" numOctaves="5" seed="2"
      stitchTiles="stitch" result="noise"/>
    <feColorMatrix type="saturate" values="0" in="noise" result="grey"/>
    <feBlend in="SourceGraphic" in2="grey" mode="soft-light"/>
  </filter>
</svg>
```

2. 在 `common.css` 的 `body` 规则中添加 `filter: url(#paper-grain);`

**方案 Y（已选）：**

将 `<filter>` 改为 overlay rect（`position:fixed; inset:0; pointer-events:none; z-index:0`），`opacity: 0.035`。仅覆盖背景层，卡片内容不受影响。

**参数规范：**

| 参数 | 值 | 说明 |
|:---|:---|:---|
| `type` | `fractalNoise` | 分形噪声，比 `turbulence` 更柔和 |
| `baseFrequency` | `0.65` | 颗粒大小约 1.5px，值越大颗粒越细 |
| `numOctaves` | `5` | 5 层分形叠加，自然粗糙感 |
| `seed` | `2` | 固定种子，每次渲染一致 |
| 混合模式 | `soft-light` | 柔光混合，比 `multiply` 更轻柔 |
| opacity（方案 Y） | `0.035` | 极低透明度，微妙可见 |

**浏览器兼容：** 以 Chrome 为准，Firefox/Safari 若渲染差异可微调 `seed` 值。

### 3.4 透出规则

所有浮层面板（卡片、侧栏、头部、弹窗）的 `--surface` 使用 `rgba(255, 255, 255, 0.92)`，即 92% 不透明白色。底下的网点从面板边缘隐约透出，产生纸张质感。弹窗（Modal）例外，使用 `--surface-opaque`（`rgb(255, 255, 255)`）完全不透明，防止与页面内容重叠。

## 五、组件规范

### 5.1 卡片（Card）（v2 增强）

**用途：** 承载独立信息块（统计数据、功能入口、用户信息）。

**基础样式：**
- 背景：`var(--surface)`
- 边框：`1px solid var(--border)`
- 圆角：`var(--radius-lg)`（`12px`）
- 内边距：`24px`（上下左右）
- 过渡：`border-color 0.15s, box-shadow 0.2s, transform 0.2s`

**stat-card 悬浮效果：**
- 边框变为 `color-mix(in oklch, var(--accent) 30%, transparent)`
- 阴影：`0 8px 24px rgba(0, 0, 0, 0.08)`
- 上移：`transform: translateY(-3px)`
- 顶部装饰线：`::before` 伪元素，2px accent 色，hover 时 `opacity: 0 → 1`，过渡 `opacity 0.15s`
- 背景装饰数字：`::after` 伪元素，`content: attr(data-decorative-num)`，72px 衬线字体，`color: var(--muted)`，`opacity: 0.06`，`pointer-events: none`

**module-card 悬浮效果（v2 与 stat-card 差异化）：**
- 边框变为 `var(--fg)`（v2：使用 fg 而非 accent，控制 accent 每屏 ≤ 2 处）
- 阴影：`0 2px 8px rgba(0, 0, 0, 0.04)`
- 上移：`transform: translateY(-2px)`（v2：比 stat-card 的 -3px 更克制）

**module-card 编号标签（v2 新增）：**
- class：`.module-card-num`
- font-family：`var(--font-mono)`
- font-size：`11px`
- letter-spacing：`0.06em`
- 颜色：`var(--muted)`
- opacity：`0.5`

**禁止：** 卡片左侧彩色边框装饰、卡片内渐变背景、卡片间投影堆叠。

### 5.2 按钮（Button）

#### 5.2.1 深色按钮（`.btn-primary`）

**用途：** 页面主操作（新增、提交、确认）。每个屏幕最多 1 个。

| 属性 | 默认态 | 悬浮态 |

| 边框 | `var(--accent)` | `var(--accent)` |
| 变换 | 无 | `scale(1.03)` |
| 过渡 | `all 0.15s` | — |

#### 5.2.2 浅色/边框按钮（`.btn-secondary`）

**用途：** 次要操作（取消、返回、重置）。可多个。

| 属性 | 默认态 | 悬浮态 |
|:---|:---|:---|
| 背景 | `transparent` | `var(--hover-bg)`（`rgb(245, 244, 237)`） |
| 文字 | `var(--fg)` | `var(--accent)` |
| 边框 | `var(--border)` | `var(--accent)` |
| 变换 | 无 | `scale(1.03)` |
| 过渡 | `all 0.15s` | — |

#### 5.2.3 幽灵按钮（`.btn-ghost`）

**用途：** 表格行内操作（编辑、查看详情）、轻量链接式操作。

#### 5.2.4 小号按钮（`.btn-sm`）

在任何按钮类型上追加 `.btn-sm`：
- padding：`5px 12px`
- 字号：`12px`

#### 5.2.5 按钮尺寸枚举

| 尺寸 | padding | 字号 | 用途 |
|:---|:---|:---|:---|

### 5.3 表格（Table）

#### 5.3.1 基础结构

- 容器：`.data-panel`，背景 `var(--surface)`，边框 `1px solid var(--border)`，圆角 `var(--radius-lg)`
- 基础 `table`：`border-collapse: separate; border-spacing: 0`
- 表头 th：背景 `var(--bg)`，字号 `11px`，等宽字体，`text-transform: uppercase`，`letter-spacing: 0.04em`，颜色 `var(--muted)`，底边框 `1px solid var(--border)`
- 表格 td：padding `12px 16px`，`vertical-align: middle`

#### 5.3.2 列间竖线

列与列之间使用 `::after` 伪元素绘制竖线，颜色 `var(--col-line)`（`rgb(240, 238, 230)`）。

| 位置 | 竖线上下留白 | 说明 |
|:---|:---|:---|
| 表头 th | `top: 25%; bottom: 25%` | 竖线较短，居中 |
| 表体 td | `top: 15%; bottom: 15%` | 竖线较长，接近行高 |
| 最后一列 | 不绘制 | `th:not(:last-child)::after` / `td:not(:last-child)::after` |

竖线在行与行之间断开，不连通。实现方式：`border-collapse: separate` + 行底边框 + `::after` 伪元素。

#### 5.3.3 行样式

| 状态 | 样式 |
|:---|:---|
| 默认 | 无特殊背景 |
| 奇数行 | `background: var(--stripe)`（`rgba(0, 0, 0, 0.025)`） |
| 悬浮行 | `background: var(--hover-bg)`（`rgb(245, 244, 237)`） |
| 行底边框 | `border-bottom: 1px solid var(--border)` |
| 最后一行 | 无底边框 |

#### 5.3.4 数据格式

| 数据类型 | 格式 | 字体 |
|:---|:---|:---|

### 6.2 过渡时间规范（v2.1 重构）

**过渡（transition）— 组件级交互反馈：**

| 过渡类型 | 时间 | 曲线 | 说明 |
|:---|:---|:---|:---|
| 背景/边框/文字色 | `0.12s ~ 0.15s` | `ease`（默认） | 轻量状态切换 |
| 变换（scale/translate） | `0.15s ~ 0.2s` | `ease`（默认） | 位移和缩放 |
| 箭头旋转 | `0.2s` | `ease`（默认） | 下拉框箭头状态切换 |

**@keyframes 动画 — 页面级入场编排（v2.1 重构）：**

@keyframes 使用专用曲线 `cubic-bezier(0.22, 1, 0.36, 1)`（easeOutExpo 近似），不使用 `ease`。

**四个核心 @keyframes：**

| 名称 | 效果 | 用途 |
|:---|:---|:---|
| `fadeUp` | `opacity: 0→1` + `translateY(14px→0)` | 卡片、section、page-header（主入场） |
| `fadeIn` | `opacity: 0→1` | 表格行、日志条目、footer（纯淡入） |
| `slideRight` | `opacity: 0→1` + `translateX(-10px→0)` | 侧栏菜单项（从左侧滑入） |
| `headerReveal` | `opacity: 0→1` + `translateY(-8px→0)` | 顶部栏（从上方滑入） |

```css
@keyframes fadeUp {
    from { opacity: 0; transform: translateY(14px); }
    to   { opacity: 1; transform: translateY(0); }
}
@keyframes fadeIn {
    from { opacity: 0; }
    to   { opacity: 1; }
}
@keyframes slideRight {
    from { opacity: 0; transform: translateX(-10px); }
    to   { opacity: 1; transform: translateX(0); }
}
@keyframes headerReveal {
    from { opacity: 0; transform: translateY(-8px); }
    to   { opacity: 1; transform: translateY(0); }
}
```

**入场编排时间线（全序列约 1.5s）：**

|:---|:---|:---|:---|:---|

| `0.21s` | 侧栏菜单项第 2 个 | `slideRight` | `0.3s` | `cubic-bezier(0.22, 1, 0.36, 1)` |
| ... | 间隔 30ms 递增 | ... | ... | ... |

## 七、交互逻辑规范

### 7.1 何时使用深色按钮 vs 浅色按钮

- **深色按钮（`.btn-primary`）：** 每个功能区域的唯一主操作。如"新增用户"、"确认提交"、"办理入住"。每个屏幕可见区域内最多 1 个。
- **浅色按钮（`.btn-secondary`）：** 次要操作或否定性操作。如"取消"、"重置"、"返回"。可多个并列。
- **幽灵按钮（`.btn-ghost`）：** 表格行内操作、导航链接式操作。如"编辑"、"查看"、"处理"。每行可多个。

### 7.2 弹窗透明度规则

弹窗（Modal）背景**必须使用 `var(--surface-opaque)` 完全不透明**，不得使用 `var(--surface)`（`rgba(255, 255, 255, 0.92)`）。原因：弹窗覆盖在页面内容上方，半透明背景会导致弹窗内容与底层页面内容视觉重叠，降低可读性。

### 7.3 表格列竖线断开规则

列间竖线**必须在行与行之间断开**，不得从表头到表尾贯通。实现方式：`border-collapse: separate` + 每行独立 `border-bottom` + `td::after` 伪元素绘制竖线（带 `top/bottom` 留白）。竖线颜色 `var(--col-line)`（`rgb(240, 238, 230)`），比行底边框色 `var(--border)`（`rgb(235, 230, 223)`）更浅，形成层级区分。

### 7.4 空状态处理（v2 增强）

表格无数据时，不得显示空白表格骨架。必须显示居中空状态提示（`.empty-state`）：

**通用规范：**
- 图标：灰色描线 SVG，`48px × 48px`（v2 从 32px 增大），颜色 `var(--border)`
- 容器：与数据表格相同的面板样式（背景、边框、圆角）
- 描述文字：`12px`，颜色 `var(--muted)`，最大宽度 `40ch`

**双模式区分：**
- `no-data`（初始无数据）：标题"暂无数据"，描述"当前没有任何记录，可以点击下方按钮添加"，附引导操作按钮（如"新建用户"）
- `no-result`（搜索无结果）：标题"未找到匹配结果"，描述"当前筛选条件下没有找到匹配的记录，请调整筛选条件后重试"，无引导按钮

### 7.5 删除操作双确认

删除操作必须执行双重确认：
1. 第一次：点击删除按钮后弹出确认弹窗，显示待删除项名称
2. 第二次：弹窗中点击"确认删除"按钮执行操作
3. 禁止单击直接删除

### 7.6 加载状态

按钮提交操作时必须显示加载态：
- 按钮文字替换为加载图标（旋转 spinner）
- 按钮设为 `disabled` 状态
- 操作完成后恢复

### 7.7 列表页骨架屏加载（v2 新增）

数据请求发出时，表格内容替换为骨架屏 shimmer 动画，替换原有的"加载中..."文字。

**规范：**
- 骨架屏行数：默认 5 行
- 骨架屏列数：必须与实际表格 `<th>` 数量一致（通过 `colCount` 参数传入）
- shimmer 动画循环：`1.5s linear infinite`
- 数据返回后：先清空骨架屏，再渲染真实数据 + stagger 入场动画

### 7.8 表格行 stagger 入场（v2.1 重构）

数据加载完成后，表格行逐行延迟入场。v2.1 从 jQuery `.delay().animate()` 重构为 CSS `@keyframes` + JS 动态 `animation-delay`：

- 动画：`fadeIn`（opacity 0→1）
- 时长：`350ms/行`
- 曲线：`ease`
- 初始延迟：`0.95s`（配合全局编排时间线）
- 行间延迟：`50ms/行`
- 上限：超过 20 行时仅对前 20 行做 stagger，其余行直接显示（性能保护）

```css
.stagger-row td {
    opacity: 0;
    animation: fadeIn 0.35s ease both;
}
```

```js
// JS 设置每行动态延迟
$tbody.find('tr').each(function(i) {
    if (i >= 20) return;
    $(this).css('animation-delay', (0.95 + i * 0.05) + 's')
           .addClass('stagger-row');
});
```

### 7.9 Dashboard 数字 count-up（v2.1 升级）

Dashboard 统计数字从 0 滚动到目标值。v2.1 升级为 `ease-out-cubic` 缓动 + `IntersectionObserver` 触发：

- 实现：`requestAnimationFrame`（非 CSS animation）
- 时长：`800ms`（v2.1 从 600ms 加长，配合 ease-out-cubic 的从容感）
- 缓动：`ease-out-cubic`：`1 - (1 - t)^3`（v2.1 从线性升级）
- 触发方式：`IntersectionObserver`（threshold 0.3），卡片进入视口时触发（v2.1 从 AJAX 回调直接调用升级）
- 数字为 0 或负数时直接显示，不触发动画
- 支持千位分隔符（`data-sep` 属性，如 `1,284`）

```js
function countUp(elementId, target, useSeparator) {
    var el = document.getElementById(elementId);
    if (!el || target <= 0) {
        if (el) el.textContent = useSeparator ? target.toLocaleString('en-US') : target;
        return;
    }
    var duration = 800;
    var startTime = null;
    function step(timestamp) {
        if (!startTime) startTime = timestamp;
        var elapsed = timestamp - startTime;
        var progress = Math.min(elapsed / duration, 1);
        var ease = 1 - Math.pow(1 - progress, 3);  // ease-out-cubic
        var current = Math.round(target * ease);
        el.textContent = useSeparator ? current.toLocaleString('en-US') : current;
        if (progress < 1) requestAnimationFrame(step);
    }
    requestAnimationFrame(step);
}
```

## 九、文件命名与引用规范
