## 一、设计目标

### 1.1 量化指标
- 页面首屏加载时间必须控制在2秒以内
- AJAX请求响应处理时间必须控制在500毫秒以内
- 所有列表页必须覆盖四种状态：正常数据、加载中（含32px SVG图标）、空数据（含32px SVG图标）、请求错误（可点击重试链接）

### 1.2 约束条件
- 前端技术栈：JSP + Bootstrap 5 + jQuery 3.6 + JSTL
- 认证方式：Session（Cookie）
- 视图解析器配置：前缀`/WEB-INF/jsp/`，后缀`.jsp`
- 静态资源路径：`/static/`
- 项目上下文路径：`/dorm-ms`
- 统一AJAX请求封装：`$.ajaxRequest(url, method, data, successCallback, errorCallback)`
- 统一返回格式：`{code, msg, data, extra}`
- 所有颜色必须使用`rgb()`/`rgba()`格式，禁止hex（`#xxx`）
- 所有功能图标必须使用内联SVG（描线风格，stroke-width:1.6），禁止emoji、禁止FontAwesome `<i>` 标签
- 设计令牌定义在独立文件`tokens.css`中，所有CSS文件必须通过CSS变量引用颜色/字体/间距/圆角


## 二、术语表

| 术语 | 说明 |
|------|------|
| 设计令牌（Design Tokens） | 定义在`tokens.css:root`中的CSS自定义属性，含颜色/字体/字号/间距/圆角/布局变量 |
| 半调网点 | body背景的`radial-gradient`圆形网点底纹，网点半径0.8px、间距16px、色值`rgb(237, 234, 229)` |
| 斑马条纹 | 表格奇数行`var(--stripe)`背景（`rgba(0,0,0,0.025)`），偶数行透明 |
| 列间竖线 | 表格列之间通过`::after`伪元素绘制的竖线，颜色`var(--col-line)`，行与行之间断开不连通 |
| 四状态覆盖 | 列表页必须实现的四种UI状态：加载中（时钟SVG）、空数据（inbox SVG）、请求错误（重试链接）、正常数据 |
| 二次确认 | 删除、状态变更等敏感操作前弹出确认对话框（`$.confirm`） |
| 模糊查询 | 使用LIKE '%keyword%'匹配的查询方式，参数名统一使用`studentNo` |
| `.cselect` | 自定义下拉选择框组件，替代原生`<select>`，保持风格统一 |
| `.detail-panel` | 详情页专用面板组件，低耦合，独立于`.data-panel`和`.form-container` |
| 强制修改密码 | 首次登录用户必须修改初始密码，模态框通过`hide.bs.modal`事件拦截关闭 |


## 三、技术栈选型

| 组件 | 版本 | 用途 | 说明 |
|------|------|------|------|
| Bootstrap | 5.x | 栅格布局、模态框基础结构、工具类 | CSS变量通过tokens.css覆盖主题色 |

## 五、CSS加载规范

### 5.1 加载顺序（强制）

所有业务页面必须在`<head>`中按以下顺序加载CSS：

```html
<!-- 1. Bootstrap CSS（可选，common.css已覆盖主题变量） -->
<link rel="stylesheet" href="${pageContext.request.contextPath}/static/vendor/bootstrap/css/bootstrap.min.css">
<!-- 2. 设计令牌（必须第一位自定义CSS） -->
<link rel="stylesheet" href="${pageContext.request.contextPath}/static/css/tokens.css">
<!-- 3. 公共样式（必须在tokens.css之后） -->
<link rel="stylesheet" href="${pageContext.request.contextPath}/static/css/common.css">
<!-- 4. 页面专有样式（可选，如login.css、error.css） -->
```

### 6.2 header.jsp

**功能**：
- 显示系统Logo + 角色标签（管理员=accent色，宿管/学生=accent-2色）
- 用户头像（姓名首字）+ 下拉菜单（修改密码、退出登录）
- 修改密码模态框（Bootstrap Modal，首次登录强制不可关闭）
- 移动端侧边栏切换按钮（≤768px显示）

**修改密码模态框**：
- 输入新密码（6-20位）+ 确认密码（须一致）
- 前端校验后通过`$.ajaxRequest`提交`POST /updatePassword`
- 成功后清除`needChangePassword`标记，跳转登录页
- 首次登录时：通过`header.js`中Bootstrap原生API创建Modal实例，`backdrop: 'static', keyboard: false`
- 非首次登录时：允许正常关闭
- Edge兼容：使用`bootstrap.Modal.getInstance()`空值保护，替代jQuery `.modal('dispose')`（参见§6.2 兼容性说明）

**修改密码模态框技术细节**：
- 首次登录（forceChange=true）：`forceChangeTip`显示警告文字，`btnClosePasswordModal`隐藏，`hide.bs.modal`事件被拦截
- 非首次（forceChange=false）：`forceChangeTip`隐藏，`btnClosePasswordModal`显示，`hide.bs.modal`事件解除
- 模态框实例通过`bootstrap.Modal.getInstance(el)`检查是否存在后决定是否dispose，防止Edge在未初始化元素上抛TypeError
- 提交按钮禁用时文本改为"提交中..."

### 6.3 sidebar.jsp

**功能**：
- 通过JSTL判断`sessionScope.loginUser.roleType`按角色动态渲染菜单
- 学生角色不显示侧边栏（`<c:if test="${roleType != ROLE_STUDENT}">`包裹）
- 菜单项分类使用`.sidebar-section`眉标分隔（等宽字体、11px、uppercase）
- 当前页面高亮通过URL路径匹配（`common.js`中实现）

**三类角色菜单结构**：
- 管理员：系统管理（系统总览/用户管理/操作日志）→ 公寓管理（楼栋/房间/床位）→ 入住管理（入住登记/调宿管理）→ 日常事务（报修/晚归/访客）
- 宿管：公寓信息（楼栋/房间/床位，只读）→ 入住管理（入住登记/调宿审批）→ 日常事务（报修处理/晚归登记/访客登记）
- 学生：个人中心（个人信息/修改密码）→ 住宿管理（住宿信息/调宿申请）→ 日常服务（报修服务/晚归记录）

**激活态样式**：左边框`2px solid var(--accent)` + 背景`var(--accent-soft)` + 文字`var(--accent)` + 字重500。

### 6.4 student_tabs.jsp

学生端水平标签导航，sticky定位在header下方：
- 标签项：我的主页、个人信息、住宿信息、调宿申请、报修服务、晚归记录
- 激活态：底部`2px solid var(--accent)`边框 + `var(--accent)`文字色 + 字重500
- 通过`requestScope['javax.servlet.forward.request_uri']`匹配当前路径
- 移动端支持横向滚动

### 6.5 footer.jsp

页脚组件，显示版权信息`© 2026 高校公寓管理系统`和`SSM 框架 · 课程设计项目`。


## 七、公共JS设计

### 7.1 common.js — 核心工具函数

| 函数 | 签名 | 说明 |
|------|------|------|
| `$.ajaxRequest` | `(url, method, data, success, error)` | 统一AJAX封装，POST自动JSON序列化、统一错误码处理 |
| `$.toast` | `(type, message, duration)` | Toast提示，顶部居中，SVG图标，默认3秒。类型：success/warning/error/info |
| `$.confirm` | `(message, onConfirm, onCancel, title)` | 二次确认弹窗，自定义模态框（非Bootstrap modal） |
| `$.buildUrl` | `(url)` | 拼接项目上下文路径 |
| `$.formatDate` | `(dateStr, format)` | 日期格式化，默认`yyyy-MM-dd HH:mm:ss` |
| `$.renderPagination` | `(pageInfo, containerId, onPageChange [, pageSize, onPageSizeChange])` | 渲染分页组件（.page-btn样式），可选pageSize下拉选择器 |
| `$.renderPageSizeCselect` | `(currentPageSize)` | 渲染每页条数选择器（.cselect组件） |
| `$.initCustomSelect` | `()` | 初始化页面中所有.cselect元素为自定义下拉框 |
| `$.updateCselectOptions` | `(cselectEl, options)` | 动态更新.cselect的选项列表 |
| `$.navigate` | `(url)` | 页面跳转 |
| `$.buildPageParams` | `(pageNum, pageSize)` | 构建分页参数对象 |
| `$.fn.serializeJSON` | `()` | 表单序列化为JSON对象 |
| `$.handleError` | `(xhr, status, error)` | 统一HTTP错误处理 |

**错误码统一处理**：
- 200 → `successCallback`
- 401 → Toast"未登录或登录已过期"，1.5秒后跳转登录页
- 403 → Toast"无权限访问"
- 其他 → `errorCallback`（若未提供则Toast显示`result.msg`）
- HTTP层错误（0/401/403/404/408/500/timeout/parsererror）→ `$.handleError`

**$.renderPagination 设计要求**：
- 页码按钮使用`.page-btn`（32px×32px，`var(--radius)`圆角，`var(--font-mono)`字体）
- 信息文字格式："共 X 条记录，第 X/X 页"
- 可选pageSize参数：传入时在分页栏左侧渲染每页条数.cselect下拉（10/20/50）
- 激活页：`var(--accent)`背景 + `var(--surface)`文字
- 禁用态：opacity 0.4

| 函数 | 说明 |
|------|------|
| `showChangePasswordModal(forceChange)` | 显示修改密码模态框，forceChange控制是否强制不可关闭 |

**首次登录强制修改密码流程**：
1. 页面加载时检查`window.needChangePasswordFlag`（由JSP输出session值）
2. 若为`'true'`，调用`showChangePasswordModal(true)`
3. 模态框通过Bootstrap原生API创建实例：`new bootstrap.Modal(el, {backdrop: 'static', keyboard: false})`
4. 关闭事件`hide.bs.modal`被拦截，点击关闭按钮（已隐藏）或遮罩层均无效
5. 密码修改成功后解除事件拦截，跳转登录页

**Edge兼容性说明**：
- 不使用jQuery `.modal('dispose')`，因其在未初始化元素上调用`getInstance()`返回`null`后访问`.dispose()`在Edge中抛出TypeError
- 改用`bootstrap.Modal.getInstance(el)`空值检查，存在实例才dispose，随后通过`new bootstrap.Modal()`创建新实例
- `backdrop`和`keyboard`按`forceChange`参数动态设置，非强制场景允许正常关闭

### 7.3 页面脚本引入顺序（强制）

```html
<!-- 1. jQuery -->
<script src="${pageContext.request.contextPath}/static/js/jquery.min.js"></script>
<!-- 2. Bootstrap JS -->
<script src="${pageContext.request.contextPath}/static/vendor/bootstrap/js/bootstrap.bundle.min.js"></script>
<!-- 3. 公共JS -->
<script src="${pageContext.request.contextPath}/static/js/common.js"></script>
<!-- 4. 导航栏JS（必须传入needChangePasswordFlag后加载） -->
<script>window.needChangePasswordFlag = '${sessionScope.needChangePassword}';</script>
<script src="${pageContext.request.contextPath}/static/js/header.js"></script>
<!-- 5. 页面专属JS（内联） -->
<script>/* 页面逻辑 */</script>
```

> 登录页例外：仅加载jQuery + common.js，不加载Bootstrap JS和header.js。登录请求直接使用`$.ajax`（不使用`$.ajaxRequest`以避开401统一拦截逻辑）。

## 九、请求规范

### 9.1 统一请求方式

| 场景 | 方式 | 说明 |
|------|------|------|
| 业务GET/POST | `$.ajaxRequest` | POST自动JSON序列化，统一错误码处理 |
| 登录 | `$.ajax` + JSON | 直接调用以避免401被`$.ajaxRequest`拦截跳转 |
| 文件上传 | `$.ajax` + FormData | `processData:false, contentType:false` |

### 9.2 参数传递规范

- 空值不传递：查询条件为空时不添加到参数对象中
- 分页参数：统一使用`pageNum`、`pageSize`
- 学号查询参数名：统一使用`studentNo`
- 模糊查询参数：空值不传，避免null序列化为字符串"null"
- 空字符串`''`和`undefined`等同处理，不放入queryParams

### 9.3 文件上传规范

- 仅CSV文件（扩展名校验`.csv`）
- 文件大小限制1MB
- 使用FormData + `$.ajax`
- 后端返回`ImportResultDTO`（含成功数、失败数、失败明细）
- 导入按钮disabled时显示spinner图标

### 9.4 XSS防护规范

- 所有拼入onclick的JS字符串参数必须做`.replace(/'/g, "\\'")`转义
- 所有拼入HTML title属性的内容必须做`.replace(/"/g, '&quot;')`转义
- 长文本截断后使用title属性显示完整内容
- 操作日志请求参数截断50字符后使用title显示完整内容（HTML转义）


## 十、数据流向

### 10.1 页面加载流程

```
用户访问URL → DispatcherServlet
→ LoginInterceptor（校验Session，未登录→/login）
→ PermissionInterceptor（校验角色权限，越权→403）
→ Controller（返回视图名称）
→ ViewResolver（拼接 /WEB-INF/jsp/ + 视图名 + .jsp）
→ JSP渲染（JSTL + EL + session数据）
→ HTML响应 → 浏览器渲染
→ jQuery $(document).ready()
  → common.js：初始化.cselect、侧边栏切换、退出登录绑定、全局AJAX错误处理
  → header.js：检查needChangePasswordFlag，必要时弹出强制修改密码模态框
  → 页面专属JS：loadData() / loadDetail() 等
```

### 10.2 AJAX请求流程

```
用户触发交互 → JS收集数据 → 前端校验
→ $.ajaxRequest(url, method, data, success, error)
  → $.buildUrl(url) 拼接上下文路径
  → POST: JSON.stringify(data) + Content-Type: application/json
  → GET: 数据作为query参数
→ 后端处理后返回JSON {code, msg, data, extra}
→ 前端处理：
  code=200 → successCallback（更新DOM、Toast成功提示）
  code=401 → Toast"未登录" → 1.5s后跳转/login
  code=403 → Toast"无权限访问" → errorCallback
  其他 → errorCallback 或 Toast显示msg
```

### 10.3 分页查询流程

```
页面加载 → 初始化pageQueryParams = {pageNum:1, pageSize:10}
→ loadData(pageQueryParams) → 收集筛选条件（空值排除）
→ $.ajaxRequest(api, 'GET', queryParams, renderCallback)
→ 成功后 renderTable(data.list) + $.renderPagination(data, id, onPageChange, pageSize, onPageSizeChange)
→ 用户点击页码/切换每页条数 → 更新参数 → loadData()
```

### 10.4 修改密码流程

```
首次登录 → AuthController设置session.needChangePassword=true
→ 页面渲染 window.needChangePasswordFlag = 'true'
→ header.js检测 → showChangePasswordModal(true)
→ 模态框实例：new bootstrap.Modal(el, {backdrop:'static', keyboard:false})
→ 用户输入新密码+确认 → 前端校验
→ $.ajaxRequest POST /updatePassword → 成功 → toast → 1.5s后跳转/login
```
