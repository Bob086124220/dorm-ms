## 一、ECharts 图表主题设计

### 1.1 图表色板（5 色，全部派生自已有 token）

| 序号 | token         | 色值                                                  | 用途                       |
| :--- | :------------ | :---------------------------------------------------- | :------------------------- |
| 1    | `--accent`    | `rgb(196, 69, 58)`                                    | 主系列（报修、关键指标）   |
| 2    | `--accent-2`  | `rgb(212, 132, 90)`                                   | 次系列（晚归、辅助指标）   |
| 3    | `--status-ok` | `rgb(46, 125, 111)`                                   | 正面指标（完成率、入住率） |
| 4    | `--muted`     | `rgb(122, 112, 103)`                                  | 中性数据（对比线、基准线） |
| 5    | 衍生暖棕      | `color-mix(in oklch, var(--fg) 40%, var(--accent-2))` | 第 5 系列（访客等）        |

**约束校验：** 无新 hex 引入，全部通过 `var()` 或 `color-mix()` 派生。

### 1.4 图表交互规范

| 交互             | 实现                                                         | 约束                                  |
| :--------------- | :----------------------------------------------------------- | :------------------------------------ |
| 鼠标悬停柱/线/饼 | tooltip 弹出 + 高亮当前项                                    | tooltip 背景 `#FFFFFF` 完全不透明     |
| 柱状图悬停       | 当前柱加深 10%                                               | 不使用 `emphasis.scale`（避免弹跳感） |
| 折线图悬停       | 当前线加粗至 3px + 显示圆点                                  | 其余线条降至 30% opacity              |
| 饼图悬停         | 当前扇区外扩 8px + 显示标签                                  | `emphasis.scaleSize: 8`               |
| 图表窗口 resize  | `window.addEventListener('resize', ...)` 调用 `chart.resize()` | 必须实现，否则小屏图表溢出            |

### 1.5 prefers-reduced-motion 降级

ECharts 图表和轮播在用户开启「减弱动态」偏好时必须降级：

```js
/* 全局：检查 prefers-reduced-motion */
var prefersReducedMotion = window.matchMedia('(prefers-reduced-motion: reduce)').matches;
```

- **图表动画：** `prefersReducedMotion` 为 true 时设置 `animationDuration: 0`（所有图表立即渲染，无过渡）
- **轮播自动播放：** `prefersReducedMotion` 为 true 时禁用自动轮播，仅保留手动切换
- **轮播切换动画：** `prefersReducedMotion` 为 true 时切换为 `animationDuration: 0.01ms`

实现方式：

```js
/* ECharts 图表初始化时 */
var chartOption = echarts.util.clone(MAGAZINE_THEME);
if (prefersReducedMotion) {
    chartOption.animationDuration = 0;
}
myChart.setOption(chartOption);

/* 轮播初始化时 */
if (prefersReducedMotion) {
    clearInterval(autoPlayTimer);  /* 禁用自动播放 */
}
```

### 2.4 JS 初始化

```js
/**
 * 初始化 SimpleMDE 编辑器
 * @param {string} textareaId - textarea 元素 ID
 * @returns {SimpleMDE} 编辑器实例
 */
function initEditor(textareaId) {
    var editor = new SimpleMDE({
        element: document.getElementById(textareaId),
        spellChecker: false,           /* 禁用拼写检查（中文环境无意义） */
        status: false,                 /* 隐藏底部状态栏 */
        toolbar: [
            'bold', 'italic', 'heading', '|',
            'quote', 'unordered-list', 'ordered-list', '|',
            'link', 'image', '|',
            'preview', 'side-by-side', '|',
            'guide'
        ],
        renderingConfig: {
            codeSyntaxHighlighting: false  /* 不引入高亮库 */
        }
    });
    return editor;
}
```

### 2.5 Side-by-side 布局

SimpleMDE 的 side-by-side 模式默认各占 50%。杂志风建议编辑区略宽：

```css
/* Side-by-side 模式 — 编辑区 60% + 预览 40% */
.editor-wrapper .CodeMirror-sided {
    width: 60% !important;  /* 覆盖 SimpleMDE 默认的 50% */
}

.editor-wrapper .editor-preview-side {
    width: 38%;
    margin-left: 2%;
    border-left: 1px solid var(--border);
    padding: var(--gap-lg);
    overflow-y: auto;
}
```

> 注：此处 `!important` 用于覆盖 SimpleMDE 内联样式的 `width: 50%`，无法通过选择器特异性替代。这是 SimpleMDE 的已知限制。

## 三、轮播无图策略（方案 C：半调网点 + 边缘色带）

### 3.1 结构

```
┌──┬──────────────────────────────────────┐
│▓▓│  公告标题（衬线字体，22px）              │
│▓▓│  公告摘要（无衬线，14px，muted 色）      │
│▓▓│  发布时间（等宽，12px）                  │
└──┴──────────────────────────────────────┘
  ↑ 4px 色带          ↑ var(--bg) + 半调网点
```

### 3.2 类型色映射

| notice_type | 名称 | 色带颜色 | token                                           |
| :---------- | :--- | :------- | :---------------------------------------------- |
| 1           | 通知 | 暖橙     | `var(--accent-2)`                               |
| 2           | 维修 | 锗红     | `var(--accent)`                                 |
| 3           | 活动 | 深绿     | `var(--status-ok)`                              |
| 4           | 紧急 | 锗红加深 | `color-mix(in oklch, var(--accent) 80%, black)` |

### 3.6 轮播行为规范

| 行为 | 参数 | 说明 |
|:---|:---|:---|
| 切换动画 | fade，300ms `cubic-bezier(0.22, 1, 0.36, 1)` | 与项目统一动画曲线 |
| 自动播放间隔 | 5000ms | 5 秒切换一张 |
| 鼠标悬停暂停 | `mouseenter` 暂停 / `mouseleave` 恢复 | 标准交互模式 |
| 手动切换 | 左右箭头 + 底部指示点 | 箭头 44px 命中区域 |
| 键盘操作 | 左右方向键切换 | 聚焦轮播区域时 |
| `prefers-reduced-motion` | 禁用自动播放，仅手动切换 | 合规降级 |

```js
/* 轮播控制核心逻辑 */
var currentIndex = 0;
var autoPlayTimer = null;
var prefersReducedMotion = window.matchMedia('(prefers-reduced-motion: reduce)').matches;

function goToSlide(index) {
    /* fade 切换 */
    $slides.eq(currentIndex).removeClass('active').css('opacity', 0);
    currentIndex = index;
    $slides.eq(currentIndex).addClass('active').css('opacity', 1);
    updateIndicators();
}

function startAutoPlay() {
    if (prefersReducedMotion) return;
    autoPlayTimer = setInterval(function() {
        goToSlide((currentIndex + 1) % total);
    }, 5000);
}

/* 悬停暂停 */
$carousel.on('mouseenter', function() { clearInterval(autoPlayTimer); });
$carousel.on('mouseleave', startAutoPlay);

startAutoPlay();
```

## 四、令牌扩展汇总

需在 `tokens.css` 的 `:root` 中新增：

```css
/* ── 图表色板 ── */
--chart-5: color-mix(in oklch, var(--fg) 40%, var(--accent-2));
```

> 仅需 1 个新 token（第 5 系列色），其余 4 色直接复用已有 token。ECharts JS 配置中直接使用 rgb 值（ECharts 不支持 CSS 变量），但这些值与 token 一一对应。

### 已有 token 依赖确认

以下 token 在本设计中被引用，需确认已在 `tokens.css` 中定义：

| token | 用于 | 确认 |
|:---|:---|:---|
| `--surface-opaque` | tooltip 背景、编辑器预览区背景 | 需确认（值应为 `rgb(255, 255, 255)` 或 `#FFFFFF`，完全不透明白） |
| `--accent-soft` | 编辑器聚焦态阴影、工具栏 active 按钮 | 需确认（值应为 `color-mix(in oklch, var(--accent) 10%, transparent)` 左右） |
| `--hover-bg` | 编辑器工具栏按钮 hover、代码块背景 | 需确认 |

若尚未定义，需在 `tokens.css` 中补充：

```css
--surface-opaque: rgb(255, 255, 255);                     /* 完全不透明表面 */
--accent-soft: color-mix(in oklch, var(--accent) 10%, transparent); /* accent 浅底色 */
--hover-bg: color-mix(in oklch, var(--fg) 5%, transparent);         /* 悬停背景 */
```

需新增 CSS 文件：`static/css/simplemde-theme.css`（SimpleMDE 覆盖样式）。
