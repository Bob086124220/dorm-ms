### A1 — SVG 图标全局引用替换

**目标**：将所有 JSP 中的 inline `<svg>` 块替换为 `<svg><use href="icons.svg#id"/></svg>`，统一图标管理。

**icons.svg 现状**：已含 49 个 symbol（原 41 + v2 补充 8），覆盖导航/操作/状态/空状态/加载/扩展全部类别。

**缺失 1 个需补充**：`icon-arrow-down`（向下箭头箭头，原型 index.html 滚动提示使用）。

```xml
<symbol id="icon-arrow-down" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.6" stroke-linecap="round" stroke-linejoin="round">
  <line x1="12" y1="5" x2="12" y2="19"/>
  <polyline points="19 12 12 19 5 12"/>
</symbol>
```

**引用方式**：在 `common.js` 顶部定义常量：

```js
$.ICON_SPRITE = '/dorm-ms/static/images/icons.svg#';
```

JSP 中使用：
```html
<svg><use href="${pageContext.request.contextPath}/static/images/icons.svg#icon-name"/></svg>
```

**替换范围**（按优先级）：

| 优先级 | 文件 | inline SVG 数量 | 说明 |

## 四、阶段 C：忘记密码

### C1 — SmsService 接口 + 默认实现

**接口**：`com.huuc.dormitory.common.sms.SmsService`

```java
public interface SmsService {
    /**
     * 发送短信验证码
     * @param phone 手机号
     * @param code  6位验证码
     * @return true=发送成功
     */
    boolean sendVerificationCode(String phone, String code);
}
```

**默认实现**：`com.huuc.dormitory.common.sms.ConsoleSmsServiceImpl`

开发/演示模式下将验证码输出到 log（`log.info("【验证码】手机号 {} → {}", phone, code)`）。

**预留生产实现**：`AliyunSmsServiceImpl` / `TencentSmsServiceImpl` 由管理员按配置切换。

### C2 — SMS 配置文件

**文件**：`src/main/resources/config/sms.properties`

```properties
# 短信平台配置（演示模式=console）
sms.provider=console
sms.api-key=
sms.api-secret=
sms.sign-name=高校公寓管理系统
sms.template-id=
sms.code-expire-seconds=300
sms.resend-interval-seconds=60
sms.max-per-hour-per-ip=5
```

Spring 加载该文件（在 `spring-service.xml` 中添加 `<context:property-placeholder>` 或通过 Java Config 读取）。

SmsService 的 Bean 按 `sms.provider` 值动态注入：
- `console` → `ConsoleSmsServiceImpl`
- `aliyun` → 预留
- `tencent` → 预留

### C3 — AuthController 扩展

| 接口 | 方法 | 说明 |
|------|------|------|
| `POST /send-code` | POST | 发送验证码到指定手机号 |
| `POST /reset-password` | POST | 验证码校验 + 重置密码 |

**`POST /send-code`**：
- 参数：`phone`
- 校验手机号存在于 `sys_user` 表中
- 校验 60s 内未重复发送（Session 记录上次发送时间）
- 校验 IP 每小时 ≤5 次（用内存 Map 计数）
- 生成 6 位随机数字验证码
- 调用 `smsService.sendVerificationCode(phone, code)`
- 将验证码 + 过期时间存入 Session

**`POST /reset-password`**：
- 参数：`phone`、`code`、`newPassword`、`confirmPassword`
- 校验验证码正确且在有效期内（5 分钟）
- 校验新密码 6-20 位，两次输入一致
- 查询 `sys_user` 中 phone 匹配的用户
- MD5 加密后更新密码
- 清除 Session 中的验证码
- 返回成功，前端提示"密码重置成功，请重新登录"

### C4 — login.jsp 忘记密码 Modal

**入口**：替换 `login.jsp` 第 110 行的 `<a href="#" class="forgot-link">`，改为调用 `showForgotPasswordModal()`。

**Modal 结构**（Bootstrap Modal，使用 `var(--surface-opaque)` 背景）：

**第一步**：输入手机号
- 输入框（phone）+ "获取验证码"按钮（60s 倒计时）
- 调用 `POST /send-code`

**第二步**：验证与重置
- 验证码输入框（6 位数字）
- 新密码输入框（6-20 位）
- 确认密码输入框
- "重置密码"按钮

**安全措施**：
- 发送验证码按钮 60s 防重复点击
- 提交防重复 `disabled`
- 错误提示：手机号不存在 / 验证码错误 / 验证码过期 / 密码格式不正确

**流程**：
```
点击"忘记密码？" → Modal 打开
→ 输入手机号 → "获取验证码"（查看控制台日志获取验证码）
→ 输入验证码 + 新密码 + 确认密码
→ 提交 → 成功 toast → 关闭 Modal → 跳回登录页
```
