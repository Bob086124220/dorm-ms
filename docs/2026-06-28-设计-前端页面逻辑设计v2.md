## 一、设计目标

### 1.1 量化指标
- 页面首屏加载时间必须控制在2秒以内
- AJAX请求响应处理时间必须控制在500毫秒以内
- 所有列表页必须覆盖四种状态：正常数据、加载中（含32px时钟SVG图标）、空数据（含32px inbox SVG图标）、请求错误（含可点击重试链接）
- 所有表单提交必须进行前端校验，校验失败时定位到对应字段并显示红色错误提示
- 敏感操作必须执行二次确认（`$.confirm`）

### 1.2 约束条件
- 前端技术栈：JSP + Bootstrap 5 + jQuery 3.6 + JSTL
- 认证方式：Session（Cookie）
- 视图解析器配置：前缀`/WEB-INF/jsp/`，后缀`.jsp`
- 静态资源路径：`/static/`
- 统一AJAX请求封装：`$.ajaxRequest(url, method, data, successCallback, errorCallback)`
- 统一返回格式：`{code, msg, data, extra}`
- 所有列表页使用`.data-panel`作为表格容器，所有详情页使用`.detail-panel`
- 所有筛选区使用`.filter-bar`，所有编辑表单使用`.form-container` + `.form-grid`
- 表格行内操作按钮必须使用`.btn-ghost`，禁止使用`.btn-primary`


## 二、术语表

| 术语 | 说明 |
|------|------|
| 模糊查询 | 使用LIKE '%keyword%'匹配，输入任意关键字可匹配包含该关键字的记录。参数名统一使用`studentNo` |
| 精确查询 | 使用=完全匹配，输入内容必须与记录完全一致 |
| 级联选择 | 选择上级选项后，下级选项通过`.cselect`动态加载对应数据 |
| 二次确认 | 执行删除、状态变更等敏感操作前，调用`$.confirm`弹出确认对话框 |
| 状态标签 | 使用`.pill-*`系列类展示状态文本，等宽字体、11px、圆角999px |
| 超时高亮 | 超过24小时未处理的报修记录，整行添加`.timeout-row`类（背景`var(--timeout-bg)`），状态后追加`.pill-danger`超时标签 |
| 四状态覆盖 | 列表页必须实现的四种UI状态：加载中（时钟SVG + "加载中..."）、空数据（inbox SVG + "暂无数据"）、请求错误（"加载失败，点击重试"链接）、正常数据 |
| 数据脱敏 | 手机号显示为`138****5678`，身份证号显示为`110101********1234` |
| 步骤指示器 | 学生端报修详情页展示处理进度的三步骤圆形指示器（`.step-circle--*`） |
| 首次登录 | 用户使用默认密码（huuc+手机号MD5）登录后，系统强制弹出修改密码模态框，`backdrop:'static'`不可关闭 |

## 四、通用交互逻辑

### 4.1 列表页面通用逻辑

#### 4.1.1 页面加载流程
1. 页面加载完成，触发`$(function(){ loadData(pageQueryParams); })`
2. `loadData`函数从`.filter-bar`筛选字段收集参数（空值排除）
3. 调用`$.ajaxRequest`发送GET请求
4. 成功回调：调用`renderTable`渲染表格，调用`$.renderPagination`渲染分页
5. 失败回调：显示"加载失败，点击重试"链接

#### 4.1.2 四状态覆盖规范（强制）

| 状态 | 实现方式 | 必须包含 |
|------|----------|----------|
| 加载中 | 初始HTML中的`<tbody>`或容器内 | 32px时钟SVG图标（`<circle>`+`<line>`）+ 文字"加载中..." |
| 空数据 | `renderTable`中list为空时 | 32px inbox SVG图标（`<polyline>`+`<path>`）+ 文字"暂无数据" |
| 请求错误 | `loadData`的error回调中 | `<a>`链接"加载失败，点击重试"，点击时重新调用`loadData` |
| 正常数据 | `renderTable`正常渲染 | 数据行+操作按钮 |

**加载中状态SVG模板**（时钟图标）：
```html
<svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.6" width="32" height="32" style="color: var(--border); margin: 0 auto 8px; display: block;">
  <circle cx="12" cy="12" r="10"/>
  <line x1="12" y1="8" x2="12" y2="12"/>
  <line x1="12" y1="16" x2="12.01" y2="16"/>
</svg>
```

**空数据状态SVG模板**（inbox图标）：
```html
<svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.6" width="32" height="32" style="color: var(--border); margin: 0 auto 8px; display: block;">
  <polyline points="22 12 16 12 14 15 10 15 8 12 2 12"/>
  <path d="M5.45 5.11L2 12v6a2 2 0 002 2h16a2 2 0 002-2v-6l-3.45-6.89A2 2 0 0016.76 4H7.24a2 2 0 00-1.79 1.11z"/>
</svg>
```

#### 4.1.3 查询逻辑
- 点击"查询"按钮：重置pageNum为1，调用`loadData`
- 点击"重置"按钮：清空所有查询条件（含`.cselect`重置为默认值），重置pageNum为1，调用`loadData`
- 分页切换：更新pageNum，调用`loadData`
- 切换每页条数：重置pageNum为1，更新pageSize，调用`loadData`

#### 4.1.4 参数传递规范
- 空值不传递：查询条件为空时（`''`、`undefined`、`null`），不添加到queryParams对象中
- 数值类型转换：pageSize使用`parseInt()`转换，`$.renderPagination`的pageSize参数支持字符串兼容（`!= null`判断）
- 模糊查询参数名：统一使用`studentNo`（非`studentId`）
- `.cselect`筛选值通过`dataset.value`读取，空字符串`''`时视为无筛选

```javascript
// 正确示例
var queryParams = {
    pageNum: params.pageNum || 1,
    pageSize: params.pageSize || 10
};
var studentNo = $('#searchStudentNo').val().trim();
if (studentNo) {
    queryParams.studentNo = studentNo;
}

// 错误示例（会导致null被序列化为字符串"null"）
var queryParams = {
    studentNo: $('#searchStudentNo').val().trim() || null  // 禁止
};
```

#### 4.1.5 表格渲染规范
- 所有列表表格使用`.data-panel`包裹+裸`<table>`标签
- 斑马条纹：奇数行`var(--stripe)`背景，悬停行`var(--hover-bg)`背景
- 列间竖线由`.data-panel td::after`自动渲染
- 编号/学号等数值字段：添加`.num`类（等宽字体+tabular-nums）
- 状态字段：使用`.pill-*`系列标签
- 日期时间：使用`$.formatDate()`格式化，默认`yyyy-MM-dd HH:mm:ss`
- 长文本截断：截断至20~50字符后加`...`，使用`title`属性显示完整内容，title内容必须做`.replace(/"/g, '&quot;')`转义
- 操作列：按钮使用`.btn-ghost.btn-sm`，禁止使用`.btn-primary`

#### 4.1.6 分页渲染规范
- 统一使用`$.renderPagination(pageInfo, containerId, onPageChange [, pageSize, onPageSizeChange])`
- 分页信息格式：`共 X 条记录，第 X/X 页`（使用`<strong>`包裹数字）
- 每页条数选择器：10/20/50，通过可选参数pageSize激活，渲染为`.cselect`组件
- 页码显示：当前页前后各2页，超出范围显示`...`
- 首页/末页：第一页禁用上一页/首页按钮（`disabled`属性），最后一页禁用下一页/末页按钮
- 页码按钮：`.page-btn`（32px×32px，`var(--radius)`圆角，`var(--font-mono)`字体）

> `common/pagination.jsp`服务端渲染分页组件已不推荐使用，所有新页面和dorm/student页面已迁移至`$.renderPagination()`。

### 4.2 表单页面通用逻辑

#### 4.2.1 表单布局规范
- 编辑表单统一使用`.form-container` + `.form-grid`体系：
  - 两列：`.form-grid`（`grid-template-columns: 1fr 1fr`）
  - 三列：`.form-grid-3`
  - 四列：`.form-grid-4`
  - 跨列字段：`.form-field.full`（`grid-column: 1 / -1`）
- 每列使用`.form-field`包裹，内含label和input
- 禁止使用Bootstrap的`row g-3`+`col-md-*`体系

#### 4.2.2 筛选区规范
- 列表页的查询条件区域统一使用`.filter-bar`（flex布局，字段自动换行，操作按钮靠右）
- 字段使用`.filter-field`包裹
- 查询按钮使用`.btn-secondary.btn-sm`（边框样式），重置按钮使用`.btn-ghost.btn-sm`
- 禁止使用`.form-container`作为筛选区容器

#### 4.2.3 表单校验规范
- 必填字段：标签后追加`<span class="required">*</span>`
- 校验失败：字段添加`is-invalid`类，下方`.invalid-feedback`显示红色错误信息
- 校验通过：移除`is-invalid`类，清空错误信息
- `.cselect`校验失败：添加`.error`类
- 提交按钮：提交过程中`prop('disabled', true)`并改文本为"提交中..."（或"保存中..."对应按钮原文）

#### 4.2.4 表单提交流程
1. 收集表单数据（含`.cselect`的`dataset.value`）
2. 逐项校验，校验失败定位到对应字段并阻止提交
3. 校验通过，禁用提交按钮
4. 调用`$.ajaxRequest`发送POST请求（`contentType: 'application/json'`，自动`JSON.stringify`）
5. 成功回调：`$.toast('success', ...)`，1.0~1.5秒后跳转到列表页
6. 失败回调：`$.toast('error', ...)`，恢复提交按钮

### 4.3 宿管端页面特殊逻辑

#### 4.3.1 未分配楼栋处理
宿管端所有查询接口可能返回"您暂未负责任何楼栋"错误。页面必须在error回调中匹配`msg.indexOf('未负责任何楼栋')`并展示专用提示：

```javascript
$.ajaxRequest('/dorm/xxx/page', 'GET', queryParams, function(result) {
    // 正常处理
}, function(result) {
    if (result.msg && result.msg.indexOf('未负责任何楼栋') !== -1) {
        $('#tableBody').html('<tr><td colspan="X" class="text-center py-4 text-muted">您暂未负责任何楼栋，请联系管理员</td></tr>');
    } else {
        // 显示加载失败重试链接
    }
});
```

### 4.4 学生选择交互逻辑

**适用页面**：`admin/checkin/checkin.jsp`、`dorm/checkin/checkin.jsp`、`admin/lateReturn/add.jsp`、`dorm/lateReturn/add.jsp`、`admin/visitor/add.jsp`、`dorm/visitor/add.jsp`

#### 4.4.1 查询流程
1. 输入学号，点击"查询"按钮（`.btn-secondary`）
2. 调用`GET /admin/user/page?username=xxx&roleType=3&pageNum=1&pageSize=10`
3. 单条结果：直接选中，显示已选学生信息，清空输入框
4. 多条结果：在`.data-panel`表格中显示查询结果列表，每行有"选择"按钮（`.btn-ghost.btn-sm`）
5. 无结果：显示内联`<div class="alert alert-warning">未找到学号包含 "xxx" 的学生</div>`

#### 4.4.2 选择流程
1. 用户点击"选择"按钮
2. 隐藏查询结果列表（`#studentResult`）
3. 显示已选学生信息（`#selectedStudent`），包含学号+姓名+"重新选择"按钮
4. 清空查询输入框
5. 显示后续表单区域（床位选择/时间输入等）

#### 4.4.3 重新选择
1. 用户点击"重新选择"按钮
2. 清除已选学生信息和隐藏学生ID
3. 隐藏已选学生信息区域
4. 隐藏后续表单区域

#### 4.4.4 HTML结构规范
查询结果和已选信息必须使用独立的div，禁止混用：

```html
<!-- 查询结果列表 -->
<div id="studentResult" style="display: none;">
    <div class="data-panel">
        <table>...</table>
    </div>
</div>
<!-- 已选学生信息 -->
<div id="selectedStudent" style="display: none;">
    <div class="alert alert-success ...">
        已选学生：<strong id="selectedStudentInfo"></strong>
        <button onclick="clearSelectedStudent()" class="btn btn-ghost btn-sm">重新选择</button>
    </div>
</div>
<!-- 无结果提示 -->
<div id="studentError" style="display: none;">
    <div class="alert alert-warning">
        <span id="studentErrorMsg"></span>
    </div>
</div>
```

#### 4.4.5 安全要求（强制）
- 学生姓名和学号拼入onclick前必须做`.replace(/'/g, "\\'")`单引号转义，防止XSS注入
- 年级和专业字段同样需要转义（虽然不常用于注入，但作为防御性措施）

### 4.5 详情页数据加载逻辑

#### 4.5.1 URL参数传递
详情页通过URL查询参数传递ID：
```
/admin/repair/detailPage?repairId=123
/admin/visitor/detailPage?visitorId=456
```

#### 4.5.2 页面结构规范

#### 4.5.3 数据加载流程
1. 页面加载完成，从URL读取ID参数（`new URLSearchParams(window.location.search)`）
2. ID不存在时显示"参数错误，未指定XXID"提示
3. 调用对应接口加载数据（加载中显示时钟SVG）

5. 失败回调：显示"加载失败，点击重试"链接

### 4.6 文件上传逻辑

**适用页面**：`admin/user/list.jsp`（批量导入）

#### 4.6.1 前端校验
1. 文件非空校验
2. 文件扩展名校验（`.csv`，通过`file.name.toLowerCase().endsWith('.csv')`）
3. 文件大小校验（≤1MB，即`file.size > 1048576`）

#### 4.6.2 上传流程
1. 创建FormData对象
2. 调用`$.ajax`发送POST请求（不能使用`$.ajaxRequest`，因其会对数据做JSON序列化）
3. 设置`processData: false, contentType: false`
4. 导入按钮disabled并显示spinner SVG（`.spinner-icon`）
5. 成功回调：解析`ImportResultDTO`，显示导入结果（全部成功=绿色alert，部分失败=黄色alert+失败明细列表）
6. 失败回调：显示错误提示

#### 4.6.3 下载模板
- "下载模板"按钮使用`.btn.btn-secondary.btn-sm`，内含下载SVG图标
- 模板路径：`/static/template/用户导入模板.csv`
- 编码：UTF-8 BOM（兼容Excel直接打开）
- 仅含表头行`username,realName,roleType,gender,phone,grade,major,className`

#### 4.6.4 CSV校验规则（后端执行）

| 字段 | 规则 | 错误信息 |
|------|------|----------|
| username | 非空、不重复 | "用户名为空"或"用户名已存在" |
| realName | 非空 | "真实姓名为空" |
| roleType | 1/2/3 | "角色类型无效" |
| gender | 1/2 或留空 | "性别值无效" |
| phone | 11位数字 | "手机号格式错误" |
| grade | roleType=3时必填 | "学生年级为空" |
| major | roleType=3时必填 | "学生专业为空" |
| className | roleType=3时必填 | "学生班级为空" |

#### 4.6.5 默认密码规则
- 所有导入用户初始密码：`huuc` + 手机号
- 加密方式：MD5
- 首次登录触发强制修改密码

```
→ header.js的$(function(){})检测 → showChangePasswordModal(true)
→ 模态框实例化：使用Bootstrap原生API的新建方式（兼容Edge）
  var existing = bootstrap.Modal.getInstance(el);
  if (existing) { existing.dispose(); }
  var modal = new bootstrap.Modal(el, {backdrop: 'static', keyboard: false});
  modal.show();
→ 输入新密码（6-20位）+ 确认密码
```

- 改用`bootstrap.Modal.getInstance(el)`空值检查+`new bootstrap.Modal()`安全创建
- `backdrop`和`keyboard`按`forceChange`参数动态控制，非首次允许正常关闭

```
用户访问URL → DispatcherServlet
→ LoginInterceptor（校验Session，未登录→/login）
→ PermissionInterceptor（校验角色权限，越权→返回JSON 403）
→ Controller（返回视图名称）
→ ViewResolver（拼接/WEB-INF/jsp/+视图名+.jsp）
→ JSP渲染（JSTL+EL+session数据，按角色渲染sidebar/student-tabs）
→ HTML响应 → 浏览器渲染
→ jQuery $(document).ready()
  → common.js：$.initCustomSelect()、侧边栏移动端切换、退出登录绑定、全局401错误处理
  → header.js：检查needChangePasswordFlag，必要时弹出强制改密模态框
  → 页面专属JS：loadData()/loadDetail()等
```

### 6.2 AJAX请求流程
```
用户触发交互 → JS收集数据 → 前端校验
→ $.ajaxRequest(url, method, data, success, error)
  → $.buildUrl(url) 拼接上下文路径/dorm-ms
  → POST: JSON.stringify(data) + Content-Type: application/json
  → GET: data作为query参数（空值已排除）
→ 后端处理后返回JSON {code, msg, data, extra}
→ 前端处理：
  code=200 → successCallback（更新DOM、$.toast、跳转）
  code=401 → $.toast warning → 1.5s后跳转/login
  code=403 → $.toast error → errorCallback
  其他 → errorCallback或$.toast显示result.msg
```

### 6.3 分页查询流程
```
页面加载 → 初始化window.pageQueryParams = {pageNum:1, pageSize:10}
→ loadData(params) → 从.filter-bar收集筛选条件（空值排除）
→ $.ajaxRequest(api, 'GET', queryParams, callback)
→ 成功后 renderTable(data.list) + $.renderPagination(data, containerId, onPageChange, pageSize, onPageSizeChange)
→ 用户点击页码/切换每页条数 → 更新参数 → loadData()
```


## 七、安全规范

### 7.1 XSS防护（强制）

| 场景 | 防护方式 | 适用页面 |
|------|----------|----------|
| onclick中拼入字符串参数 | `.replace(/'/g, "\\'")` | 所有学生选择add.jsp |
| HTML title属性中拼入内容 | `.replace(/"/g, '&quot;')` | 所有repair/list.jsp |
| 操作日志请求参数展示 | HTML转义 + title完整内容 | admin/log/list.jsp |

### 7.2 数据脱敏（强制）

| 脱敏对象 | 格式 | 正则 |
|----------|------|------|
| 手机号 | `138****5678` | `.replace(/(\d{3})\d{4}(\d{4})/, '$1****$2')` |
| 身份证号 | `110101********1234` | `.replace(/(\d{6})\d{8}(\d{4})/, '$1********$2')` |

### 7.3 操作安全
- 所有删除/状态变更操作必须通过`$.confirm()`二次确认
- 所有表单提交按钮在提交过程中必须`prop('disabled', true)`防止重复提交
- `$.ajaxRequest`双层401拦截（success回调中code=401 + HTTP status=401的`$.handleError`）
- 登录请求不经过`$.ajaxRequest`（直接使用`$.ajax`），避免401自动跳转逻辑干扰错误提示
