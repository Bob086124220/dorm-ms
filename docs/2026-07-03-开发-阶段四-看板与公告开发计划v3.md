### A7 — 轮播 CSS 注入 common.css

## 三、阶段 B：公告通知后端

### B1 — 数据库表 DDL

```sql
CREATE TABLE sys_notice (
    notice_id     BIGINT       PRIMARY KEY AUTO_INCREMENT COMMENT '公告ID',
    title         VARCHAR(100) NOT NULL              COMMENT '标题',
    content       TEXT         NOT NULL              COMMENT '内容（Markdown）',
    notice_type   TINYINT      NOT NULL DEFAULT 1    COMMENT '分类：1-通知 2-维修 3-活动 4-紧急',
    visible_scope TINYINT      NOT NULL DEFAULT 1    COMMENT '范围：1-全部 2-按楼栋',
    building_id   BIGINT       DEFAULT NULL          COMMENT '楼栋ID（scope=2时必填）',
    status        TINYINT      NOT NULL DEFAULT 1    COMMENT '状态：1-发布 0-下架',
    is_top        TINYINT      NOT NULL DEFAULT 0    COMMENT '是否置顶：0-否 1-是',
    is_banner     TINYINT      NOT NULL DEFAULT 0    COMMENT '是否上轮播：0-否 1-是',
    banner_image  VARCHAR(255) DEFAULT NULL          COMMENT '轮播图片路径（服务器本地）',
    banner_expire DATETIME     DEFAULT NULL          COMMENT '轮播过期时间',
    publisher_id  BIGINT       NOT NULL              COMMENT '发布人ID',
    publish_time  DATETIME     DEFAULT NULL          COMMENT '发布时间',
    create_time   DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    update_time   DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间'
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='公告通知表';
```

**与 v2 的差异**：
- `status` 拆分为 `status`（发布/下架）+ `is_top`（置顶），原三合一设计废弃
- 轮播查询 SQL：`WHERE is_banner = 1 AND status = 1 AND (banner_expire IS NULL OR banner_expire > NOW())`
- 可见公告查询 SQL：`WHERE status = 1 AND (scope=1 OR (scope=2 AND building_id IN (...))) ORDER BY is_top DESC, publish_time DESC`

### B6 — 公告可见性逻辑

**宿管可见范围判断**：
1. 查询该宿管管理的楼栋 ID 列表

1. 查询该学生当前入住的楼栋 ID（若未入住则仅可见 scope=1 的公告）
2. 同上 OR 逻辑

## 五、阶段 D：轮播公告组件

### D1 — 公共轮播片段

**文件**：`common/carousel.jsp`

**功能**：
- 页面加载时调用 `/common/notice/banners` 获取当前用户可见轮播公告
- 有数据且 ≥2 条：渲染轮播（左右箭头 + 指示圆点）
- 仅 1 条：渲染单张幻灯片（隐藏箭头和圆点）
- 无数据：区域完全隐藏（不渲染空 div）

**实现方式**：在 `<div id="carouselArea">` 容器中 AJAX 加载数据后动态渲染 HTML。

### D2 — 轮播项结构

**有图**（`banner_image` 不为空）：
```html
<div class="carousel-item active">
    <img src="${bannerImage}" alt="${title}" class="carousel-banner-img">
    <div class="carousel-caption">${title}</div>
</div>
```

**无图**（`banner_image` 为 null，方案 C）：
```html
<div class="carousel-item no-image active">
    <div class="type-stripe" data-type="${noticeType}"></div>
    <div class="overlay">
        <h2>${title}</h2>
        <p>${summary}</p>
        <span class="notice-time num">${publishTime} 发布</span>
    </div>
</div>
```

### D3 — 轮播 JS 行为

在 `common.js` 中实现轮播控制逻辑（参考《临时-阶段四新元素样式设计》§3.6）：

| 行为 | 参数 |
|------|------|
| 切换动画 | fade，300ms `cubic-bezier(0.22, 1, 0.36, 1)` |
| 自动播放间隔 | 5000ms |
| 悬停暂停 | `mouseenter` 暂停 / `mouseleave` 恢复 |
| 手动切换 | 左右箭头 + 底部指示点，44px 命中区域 |
| `prefers-reduced-motion` | 禁用自动播放，仅手动切换 |

**摘要（summary）**：前端从 Markdown content 截取前 100 字符（纯文本，移除 Markdown 标记），若超长则追加 "..."。

### H4 — common/notice/detail.jsp（公告详情页，独立页面）

- 内容区（max-width 860px 居中）：
  1. 眉标（类型 badge + 发布日期 + 适用范围）
  2. 标题（h1，衬线字体）
  3. 发布信息栏（发布者 + 发布时间 + 适用楼栋）
  4. Banner 区（有图=图片 320px / 无图=半调网点 + 色带 220px）
  5. Markdown 内容区（`.notice-content` + `.md-body`，背景装饰数字）
  6. 其他公告（3 条相关公告卡片）
- 页脚
- 返回顶部按钮（滚动 > 300px 显示）

**加载流程**：
1. 从 URL 参数获取 `id`
2. `GET /common/notice/{id}` 获取公告详情
3. `marked.parse(content)` → `DOMPurify.sanitize()` → 渲染

**CSS**：公告详情页样式直接内联在 `detail.jsp` 的 `<style>` 标签中（与 login.jsp 同理，不污染 common.css）。所有颜色通过 CSS 变量引用 tokens。

**DOMPurify 配置**：
```js
DOMPurify.sanitize(raw, {
    ADD_TAGS: ['input'],
    ADD_ATTR: ['type', 'checked', 'disabled']
});
```
